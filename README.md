# Slide Puzzle Lab 🧩🔬

端末内の写真やイラストを取り込んで、ブラウザ上で楽しめる**完全ローカル完結・オフライン対応**のスライドパズルWebアプリ（PWA）です。

![Slide Puzzle Lab](/public/sample.jpg)

## 特徴

- 🔒 **プライバシー配慮（端末内画像処理）**: 選択した画像は外部サーバーへ送信されず、画像処理およびパズル生成はすべて端末内（ブラウザCanvas）で完結します（※アプリ本体の配信やPWAの更新確認等を除く）。
- 📱 **PWA & オフライン対応**: 初回アクセス後は機内モードや電波の届かないオフライン環境でも起動・プレイ可能です。
- 📐 **直感的な正方形クロップ**: 写真のExif回転を自動補正し、ピンチ/ドラッグ/ズームで余白なく正方形に切り抜き可能。端数欠落のない高精度分割を実現。
- ⚙️ **柔軟な難易度設定**:
  - **分割数**: 3×3（8ピース）、4×4（15ピース）、5×5（24ピース）、6×6（35ピース）
  - **シャッフル度合い**: 軽め（総マス×3、正解位置50〜80%目安）、標準（総マス×10、20〜50%目安）、強め（総マス×30、0〜35%目安）
- 🎯 **100%解ける完成保証 & レベル別評価**: 完成状態から合法手のみでシャッフルを生成。試行評価により難易度ごとの崩れ度合いを満たす盤面を確実に返却。
- 🔢 **ピース番号表示（補助機能）**: 風景写真や単色背景などでも解きやすいよう、ワンタップでピース番号のON/OFFを切り替え可能。
- ⏱️ **タイマー・ポーズ機能**: 手動ポーズ、元画像確認中の一時停止、別タブ移動時の自動ポーズに対応。ポーズ・モーダル表示中の背後操作を完全ガード。
- 🧭 **最短手数表示（Web Worker非同期探索）**: プレイ開始時の初期配置から完成までの最短手数をパズル画面および完成ダイアログに表示。3×3および4×4ではWeb Workerで厳密解を非同期探索（3秒上限）、5×5・6×6およびタイムアウト時はマンハッタン距離による下限（`以上`）を即時フォールバック表示。ゲーム操作を一切ブロックしません。
- 🎮 **多彩な操作性**: タップ、クリック、スワイプ（Pointer Eventsによる二重実行防止）、キーボード（矢印キー）操作に完全対応。アクセシビリティ（フォーカストラップ・スクリーンリーダー配慮）にも対応。

## 技術スタック

- **フロントエンド**: React 19, TypeScript, Vite
- **スタイリング**: Tailwind CSS
- **オフライン / PWA**: `vite-plugin-pwa` (Workbox)
- **アイコン**: Lucide React
- **テスト**: Vitest, React Testing Library

## 開発・起動手順

### 必要な環境
- Node.js 18+
- npm

### インストール & 起動
```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

### ビルド & プレビュー
```bash
# 本番ビルド (PWAアセット生成)
npm run build

# ビルド結果のローカルプレビュー
npm run preview
```

### 単体テストの実行
```bash
npm run test:run
```
